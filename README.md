# bsmap — редактор базових станцій

Веб-редактор для розміщення базових станцій і їхніх секторів покриття на карті. Працює в браузері, встановлювати нічого не потрібно.

**Як користуватися:** клікніть на карту, щоб додати станцію, або знайдіть адресу через пошук у правому верхньому куті. Параметри кожної станції (азимут, радіус, ширина сектора, колір) змінюються в бічній панелі.

## Що нового

### Зручність роботи
- **Скасувати / Повторити**: кнопки внизу карти, також працюють Ctrl+Z і Ctrl+Y.
- **Автозбереження**: станції, налаштування та положення карти зберігаються в браузері. Після перезавантаження сторінки все залишається на місці.
- **Назва станції**: її можна задати окремо від адреси, вона показується жирним в інфобоксі.
- **Дублювання**: кнопка «Дублювати» створює копію станції поруч.
- **Фільтр списку**: швидкий пошук станцій за назвою чи адресою.
- **Ручка азимута**: клікніть на станцію, і на кінці сектора з'явиться ручка. Потягніть її, щоб повернути сектор.
- Інфобокс тепер переміщується разом зі станцією, коли її перетягувати.
- Нову станцію більше не можна випадково створити кліком після перетягування.

### Карта та експорт
- **Шар «Супутник»**: перемикач шарів у правому нижньому куті.
- **Експорт у GeoJSON і KML**: для QGIS, Google Earth та інших ГІС.
- Формат файлу JSON сумісний зі старими збереженнями.

### Надійність
- Пошук адреси працює швидше і стабільніше.
- Перед «Видалити все» з'являється підтвердження.
- Пошкоджений або чужий файл не зламає карту: некоректні записи пропускаються, редактор показує, скільки їх було.
- Повідомлення з'являються внизу екрана і більше не блокують роботу спливними вікнами.

```bash
python -m http.server 8765
```

Потім відкрийте `http://localhost:8765/`.
