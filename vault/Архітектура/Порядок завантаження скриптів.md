# Порядок завантаження скриптів

Скрипти підключені в кінці `<body>` і виконуються по черзі. Порядок важливий: верхньорівневий код модуля може використовувати лише те, що оголошено вище. Функції, які викликаються пізніше (обробники подій), можуть посилатися на будь-що.

| # | Файл | Чому тут |
|---|---|---|
| 0 | Leaflet 1.9.4 (unpkg, з SRI) | глобальний `L` |
| 1 | [[validate.js]] | `MARKER_SIZES`, `HEX_COLOR`, санітизація |
| 2 | [[geometry.js]] | геометрія сектора |
| 3 | [[export.js]] | використовує `sectorPoints`, `circlePoints` |
| 4 | [[ui.js]] | `el()`, `toast()` |
| 5 | [[config.js]] | `settings`, `STORAGE_KEY` |
| 6 | [[storage.js]] | `readSavedState()` потрібна для [[map.js]] |
| 7 | [[map.js]] | створює `map` одразу при завантаженні |
| 8 | [[geocoding.js]] | |
| 9 | [[stations.js]] | |
| 10 | [[history.js]] | `commit()`, `undo()`, `redo()` |
| 11 | [[settings-ui.js]] | шукає елементи налаштувань у DOM |
| 12 | [[main.js]] | викликає `init()` — має бути останнім |

> [!warning] Пастка
> Не називати глобальні змінні так само, як властивості `window` (`history`, `name`, `status`…). Тому стек історії називається `undoStack`. Див. [[history.js]].
