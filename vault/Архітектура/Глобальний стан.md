# Глобальний стан

| Змінна | Де оголошена | Що зберігає |
|---|---|---|
| `settings` | [[config.js]] | глобальні налаштування ([[Глобальні налаштування]]) |
| `map` | [[map.js]] | екземпляр `L.map` |
| `savedState` | [[map.js]] | прочитаний на старті [[Стан у localStorage]] |
| `currentBaseLayer` | [[storage.js]] | назва базового шару («Карта»/«Супутник») |
| `stations` | [[stations.js]] | масив станцій ([[Модель станції]]) |
| `selectedId` | [[stations.js]] | id виділеної станції або `null` |
| `azimuthHandle` | [[stations.js]] | маркер [[Ручка азимута]] |
| `isRecentlyDragged` | [[stations.js]] | 300 мс після перетягування — блокує створення станції кліком |
| `undoStack`, `undoIndex` | [[history.js]] | знімки для [[Скасування і повтор]] |
| `geocodeCache` | [[geocoding.js]] | кеш зворотного геокодування |
| `DOM` | [[settings-ui.js]] | посилання на поля налаштувань |

Станції шукаються за `id` (`getStation(id)`), а не за індексом у масиві — індекси зсуваються після видалення.
