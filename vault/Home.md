# bsmap — редактор базових станцій

Веб-редактор для розміщення базових станцій і секторів покриття на карті Leaflet. Працює в браузері без збірки.

- Репозиторій: [bsmap/bsmap](https://github.com/bsmap/bsmap)
- Локальна папка: `C:\Users\Arsen\custom_scripts\bsmap`
- Стек: HTML + CSS + класичні JS-скрипти, [Leaflet 1.9.4](https://leafletjs.com), [Nominatim](https://nominatim.org), тести на `node --test`
