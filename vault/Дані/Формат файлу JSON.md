# Формат файлу JSON

Файл `base_stations.json` містить масив об'єктів:

```json
[
  {
    "name": "БС-1",
    "lat": 50.45734,
    "lng": 30.36149,
    "azimuth": 90,
    "radius": 700,
    "width": 120,
    "color": "#000000",
    "address": "Київ, вулиця Ореста Васкула, 27",
    "markerSize": 17,
    "popupLat": 50.45509,
    "popupLng": 30.36149
  }
]
```

## Сумісність
- Старі файли (до рефакторингу) не мають `name` і `markerSize`; ці поля отримують значення за замовчуванням.
- Обгортка `{ "stations": [...] }` також приймається.
- Невідомі поля ігноруються.
- Обов'язкові лише `lat` і `lng`, решта має значення за замовчуванням.

Розбір виконує `parseStationsFile` у [[validate.js]]. Модель: [[Модель станції]].
