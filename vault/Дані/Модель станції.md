# Модель станції

Об'єкт у масиві `stations` ([[stations.js]]):

| Поле | Тип | Опис |
|---|---|---|
| `id` | number | внутрішній ідентифікатор сесії, у файл не зберігається |
| `name` | string | назва, до 200 символів |
| `lat`, `lng` | number | координати станції |
| `azimuth` | number \| `''` | 0–360; `''` означає «не показувати азимут» |
| `radius` | number | радіус сектора, м |
| `width` | number \| `''` | ширина сектора 0–360; `''` ховає сектор |
| `color` | string | `#rrggbb` |
| `address` | string | адреса, може бути багаторядковою, до 2000 символів |
| `markerSize` | number | px |
| `popupLat`, `popupLng` | number | позиція інфобокса |
| `marker`, `polygon`, `popupMarker` | шари Leaflet | не серіалізуються |

Правила валідації описано в [[validate.js]]. Серіалізований вигляд: [[Формат файлу JSON]].
