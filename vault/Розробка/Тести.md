# Тести

```bash
node --test tests/
```

Потрібен Node.js 18+ (перевірено на v26). Залежностей немає.

## Як це влаштовано
- `tests/load.js` завантажує [[validate.js]], [[geometry.js]] і [[export.js]] в один `vm`-контекст, як у браузері.
- Результати копіюються через JSON: масиви з іншого `vm`-realm не проходять `deepStrictEqual`.
- `tests/bsmap.test.js` містить 10 тестів: геометрія (обернений азимут, кінець дуги), санітизація, розбір файлу, експорт GeoJSON/KML (екранування XML, колір).

## Що не покрито
DOM і Leaflet: [[stations.js]], [[history.js]], [[settings-ui.js]], [[main.js]]. Їх перевіряють вручну в браузері. Ідея автоматизувати: [[Беклог]].

> [!note]
> Тести є лише в локальній гілці `master`, на GitHub їх немає. Див. [[Git і гілки]].
