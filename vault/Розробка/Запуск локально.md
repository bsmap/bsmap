# Запуск локально

Сторінку треба відкривати через вебсервер, а не через `file://`.

```bash
cd C:\Users\Arsen\custom_scripts\bsmap
python -m http.server 8765
```

Адреса: `http://localhost:8765/bsmap.html` (локально) або `index.html` (у гілці для GitHub, див. [[Git і гілки]]).

У Claude Code для цього є конфігурація `.claude/launch.json` з назвою `bsmap`.

> [!tip]
> Після зміни CSS чи JS оновлюйте сторінку через Ctrl+F5, бо браузер кешує файли.

Для перевірки потрібен інтернет: Leaflet, тайли карти й Nominatim завантажуються зовні.
