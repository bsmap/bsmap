# Глобальні налаштування

Блок «Глобальні налаштування» в бічній панелі. Зміна значення **застосовується до всіх наявних станцій** і стає значенням за замовчуванням для нових.

| Поле | Ключ у `settings` | За замовчуванням | Діапазон |
|---|---|---|---|
| Розмір тексту | `FONT_SIZE` | 12 | 6–20 px |
| Колір азимутів | `COLOR` | `#000000` | |
| Розмір маркера | `MARKER_SIZE` | 17 | кроки з `MARKER_SIZES` |
| Радіус азимутів | `RADIUS` | 700 | > 0 м |
| Ширина азимутів | `AZIMUTH_WIDTH` | 120 | 0–360 або порожньо (ховає сектори) |
| Відступ інфобокса | `POPUP_DISTANCE` | 250 | 50–500 м, переставляє всі інфобокси |
| Геокодувати нові станції | `GEOCODE` | так | |
| Жирний / Курсив | `FONT_WEIGHT` / `FONT_STYLE` | ні | |

Налаштування зберігаються в [[Стан у localStorage]].

> [!note]
> Шрифт, жирність і курсив глобальні: у станцій немає власних налаштувань тексту.

Код: [[settings-ui.js]], [[config.js]].
