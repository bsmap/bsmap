# ADR-004: Історія через знімки стану

## Контекст
Потрібні [[Скасування і повтор]] для всіх дій зі станціями.

## Рішення
Після кожної завершеної дії `commit()` зберігає JSON усіх станцій (`serializeStations()`) у стек. Undo і redo повністю перебудовують станції зі знімка ([[history.js]]).

## Чому не патерн «команда»
- Простіше: не треба писати зворотну операцію для кожної дії.
- Той самий формат, що й у файлі та [[Автозбереження]].
- Однакові знімки не дублюються (порівнюються рядки).

## Наслідки
- Пам'ять: 100 знімків × розмір JSON. Для сотень станцій це прийнятно; для тисяч варто перейти на диференціальні знімки.
- Undo перебудовує всі шари Leaflet і список, а id станцій змінюються. Виділення скидається.
