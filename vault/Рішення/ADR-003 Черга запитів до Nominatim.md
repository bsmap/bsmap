# ADR-003: Черга запитів до Nominatim

## Контекст
[Політика використання Nominatim](https://operations.osmfoundation.org/policies/nominatim/) дозволяє не більше 1 запиту на секунду. Раніше швидкі кліки по карті й пошук відправляли запити паралельно.

## Рішення
- Усі запити (`search` і `reverse`) проходять через спільний ланцюжок Promise в `nominatimRequest()` ([[geocoding.js]]) з інтервалом 1100 мс.
- Пошук має debounce 700 мс і скасовує застарілі запити через `AbortController`.
- Зворотне геокодування кешується.

## Наслідки
- При швидких кліках станції з'являються з затримкою, по одній на секунду.
- Браузер не дозволяє встановити `User-Agent`, тож сайт ідентифікується за `Referer`.
- Для масового використання знадобиться власний сервер Nominatim, див. [[Беклог]].
