# ADR-002: Вивід тексту без innerHTML

## Контекст
Адреси з Nominatim, поля вводу та завантажених файлів вставлялися через `innerHTML`. Чужий `base_stations.json` з адресою `<img src=x onerror=...>` виконав би код на сторінці.

## Рішення
- Увесь динамічний текст виводиться через `textContent` або текстові вузли.
- Елементи створюються через `el()` з [[ui.js]]; багаторядковий текст через `textWithBreaks()`.
- `innerHTML` дозволений лише для статичного HTML, а краще й без нього.
- Дані з файлу додатково проходять [[validate.js]]: колір лише `#rrggbb`, числа в межах.

## Перевірка
Адреса `<img src=x onerror=alert(1)>` відображається як текст, елемента `img` в інфобоксі немає (перевірено в браузері).
