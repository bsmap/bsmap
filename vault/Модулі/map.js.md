# map.js

Виконується одразу при завантаженні сторінки:
1. `savedState = readSavedState()` з [[storage.js]].
2. Початковий вигляд береться зі збереженого (з перевіркою меж), інакше Київ `50.4501, 30.5234`, zoom 14.
3. Базові шари: «Карта» (OpenStreetMap) і «Супутник» (Esri World Imagery), обидва з атрибуцією. Перемикач стоїть у правому нижньому куті.
4. Події `baselayerchange` і `moveend` викликають `scheduleSave()` ([[Автозбереження]]).

Обробник кліку по карті розміщено в [[main.js]].
